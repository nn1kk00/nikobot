# nikobot
Шуточный телеграм бот
-
Создан чтобы просто в любое время бот выкладывал изображение для разрядки чата.
Если он видит что его позвали (любое слово если похоже на его имя, будь то часть слова)
-
Важные библиотеки: telebot, random
-
Использовать прямые ссылки для отправки изображения от бота
